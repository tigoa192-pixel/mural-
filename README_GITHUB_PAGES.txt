SITIO DE SOCIOLOGÍA - GITHUB PAGES

1. Crea un repositorio NUEVO en GitHub.
2. Sube estos tres archivos a la raíz:
   index.html
   style.css
   script.js
3. En el repositorio entra a Settings > Pages.
4. En Build and deployment selecciona:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
5. Pulsa Save.
6. Espera unos minutos y GitHub mostrará la URL pública de tu sitio.

IMPORTANTE:
- index.html debe quedar directamente en la raíz del repositorio.
- No cambies los nombres de los archivos.
